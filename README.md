# DigitalBurj

**Learn. Build. Transform.**

- `index.html` — static brand landing page (Academy, Studio, Business AI and the ecosystem services), wired up with favicons, web manifest and OpenGraph image.
- `brand/` — the DigitalBurj EXACT master deliverables (master artwork, logo lockups, division lockups/icons, ecosystem tiles, web/social sizes, print PDFs). See `brand/README.md` and `brand/ASSET_MANIFEST.csv`.

Open `index.html` directly in a browser, or serve the folder with any static host (e.g. `python3 -m http.server`).
